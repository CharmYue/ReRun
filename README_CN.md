# ReRun — 你的人生，再来一次

> 你睁开眼。手机屏幕显示：2015 年 1 月 1 日。
> 你记得所有的事。比特币。新冠。ChatGPT。
> 你记得未来十年每一个让你拍断大腿的瞬间。
> 这一次，你要全部抓住。

**ReRun** 是一款在终端中运行的人生 Roguelike 模拟器。你带着 10 年的未来记忆穿越回 2015 年，在真实历史事件中做出选择，试图逆天改命。

<!-- ![demo](docs/demo.gif) -->

## 特性

- **10 年真实历史** (2015-2025)：比特币暴涨暴跌、新冠疫情、AI 革命
- **有意义的选择** — 每个选项都有真实的 trade-off，没有明显的最优解
- **16 个成就** — 投资类 / 生活类 / 隐藏成就
- **精美终端 UI** — emoji、彩色面板、打字机效果
- **AI 生成事件**（可选）— 接入 OpenAI，或完全离线游玩
- **毒舌旁白** — 打破第四面墙的系统吐槽
- **可反复游玩** — 不同选择、不同事件、不同结局

## 快速开始

```bash
pip install -e .
rerun
```

或者用 Python 直接运行：

```bash
python -m rerun
```

### 启动选项

```
python -m rerun --offline    # 离线模式，无需 API key
python -m rerun --lang en    # 英文模式
python -m rerun --debug      # 调试输出
```

### AI 模式（可选）

创建 `.env` 文件来启用 AI 生成事件：

```bash
cp .env.example .env
# 编辑 .env，填入你的 OPENAI_API_KEY
```

没有 API key 也可以玩！游戏自带精心设计的事件池，离线模式完全可玩。

## 玩法说明

每年（2015-2025），你会经历：
1. **年度简报** — 真实历史背景 + 你的当前状态
2. **事件** — 2-3 个选项的人生抉择（职场/家庭/感情/投资）
3. **后果** — 数值变化、旁白吐槽，说不定还能解锁成就

你的属性包括：存款、BTC 持仓、房产、股票、压力、关系、社交、声望。每个选择都会改变平衡。

游戏结束时，你会看到结算报告——和"不穿越的普通人"对比，看看你到底是逆天改命还是不如不穿。

- [Pydantic](https://docs.pydantic.dev/) 数据模型
